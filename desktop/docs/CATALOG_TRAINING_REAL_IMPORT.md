# 商品库与知识库真实导入闭环

本文件只说明真实运营数据导入，不把导入成功包装成付款、发货、上线或模型训练完成。

## 商品库

- 入口：`/catalog/import`。
- 支持：CSV、XLSX、粘贴表格文本。
- 流程：先预览和审计，再二次确认写入 SKU。
- 验收：预览结果会复用服务端 SKU 审计，显示必填映射、图片、库存、供应商/交期、预算带和可售组合边界问题。
- 阻断：缺 SKU 编号、名称、售价，或审计返回阻断错误时，不允许写入或进入报价/出图前置。

## 知识库

- 入口：`/training/import` 的“运营 SOP / 知识”模式。
- 支持：下载 CSV 模板、粘贴 CSV/制表符文本、粘贴 JSON。
- 数据结构：写入现有 `KnowledgeEntry`，不新建平行文档库。
- 流程：先预览校验，再二次确认写入。
- 阻断：缺标题、缺正文、正文过短会阻断。
- 待复核：缺 Agent、缺标签、低质量分会标为待补齐/待复核，不会自动应用为 Agent 技能。

## 用户仍需补齐

- 真实 SKU 表。
- 真实主图和多角度图。
- 供应商名称、交期、库存、预算带。
- 可售组合边界和替代 SKU。
- 正式 SOP、真实聊天记录、人工复核后的纠错沉淀。
